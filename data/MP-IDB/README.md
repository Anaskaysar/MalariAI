# MP-IDB: Malaria Parasite Image Dataset

MP-IDB is a dataset for instance segmentation, semantic segmentation, object detection, and classification tasks.

Source: Loddo et al. (2019), http://www.neuroimaging.it/malaria_parasite_image_database

Used in this project as a zero-shot cross-dataset domain-shift stress test for Stage 1 (see main README, "MP-IDB — Cross-Dataset Domain-Shift Stress Test").
